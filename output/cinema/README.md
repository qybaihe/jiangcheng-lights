# 《江城有灯》剧情样片

2026-09-08。已实际调用 Seedance 2.0，生成三条首尾帧样片和一条 C04 重拍。按最新反馈重新剪辑为 **13 秒无声节奏样片：江面 5 秒、递面 4.5 秒、亮灯 3.5 秒**。全部保持原速，未补帧、慢放或用静止画面撑时长。本次重新剪辑没有再调用生成接口。

生成长度和镜头长度分别记录。以后先按动作与故事信息决定镜长，再选择合适的生成参数；不以统一 15 秒生成或长时间等待作为默认制作方式。
