## 改动的重点

1. 序章先接外公电话，再拿委托；外公健在、在姨妈家休养，不做离世悬念。
2. 取消解释性旁白的强制朗读。人物说短一点，实际动作多一点。
3. 四张连续照片改为一张童画的四片拼合，不要求玩家猜老人的私密往事。
4. 周伯直接说外公后来回去了；信封自然托带，不作为任务奖励故意藏谜。
5. 结尾只演一次重开门，不先用长信讲完，又在 CG 后复述。现在时收在一通约过早的电话里。
6. 吃葱、饭盒白点、扶箱底、抬凳子这些具体细节保留。武汉在生活和空间里，不靠每人朗诵城市介绍。

### 本轮实际出片结果

Seedance 返回模型为 `dreamina-seedance-2.0-260128`，任务成功；原始试片 [cinema-v3-prologue-ferry-v1.mp4](../../public/media/cinema-v3-prologue-ferry-v1.mp4) 已保存。实测 15.041667 秒、1280×720、24 fps、361 帧、无音轨，完整解码通过。

**视觉判定：需返修，不接入游戏。** 实际切点为 5.375 秒、12.333 秒，钥匙镜头约 6.96 秒，最后岸线镜头仅约 2.71 秒。密集帧中钥匙在张开掌心自行翻转，闪光过强、柄上有类字母刻印；第三镜邻楼与首镜不一致，末尾塔冠出画。不是合格的完整序章，更不是靠多停几秒就算补足剧情。

本轮以首帧查看、全片解码、每半秒和动作附近密集抽帧、实际切点检测为检查范围，没有宣称实时原速观看已通过。详见 [试片审查](prologue-trial-review.md)。只实际调用 1 次图像、1 次视频生成，没有自动追加重拍。修订方向是给钥匙独立构图与动作锚点、缩短有效动作、回岸线继续引用同一背景；全套制作待正文验收。
