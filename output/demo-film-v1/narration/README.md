|---|---|---:|---|---|

| `B.wav` | 总有人，替你留一盏灯。 | 3.560 秒 | 22.000–25.560 秒 | -19.00 / -3.61 |

WAV 为 48 kHz / 单声道 / PCM 24-bit 母版；同名 192 kbps MP3 供试听或备用。语音已经含少量前后留白，不需要额外变速。

## 声音与来源

通过项目已验证的 `text_to_audio` 专用接口真实生成。接口仅有 prompt，不暴露固定 speaker 或模型名；描述为自然温暖、正常说话的成年女旁白。同一连续录音保证本次两句音色一致，和游戏原序章属于相近风格，不声称复制或克隆原声。生成只包含这两句，无游戏原旁白重录。

初版 `audition.raw.wav` / `audition.wav` 及其 prompt、SHA、听检完整保留。初版被听检形容为 whispered，未用于最终。第 2 版在 `take-v2/`，改为正常说话支撑；这是最终选用来源。

## QA

两次针对最终选用素材的模型辅助实际音频盲听：先听第 2 版原录音，再听切好的两句归一化母版。不给模型台词，回译均逐字匹配（忽略标点），同一成年女声，温暖、清楚、自然；没有广告腔/哭腔、背景音乐、环境声、截字或失真。**这是模型辅助听检，不是人耳试听。**

切点来自原声实际静音边界：A 取原声 0.360–4.160；B 取 5.960–9.520。保留超过 120 ms 的头部和 140 ms 的尾部余量，8/12 ms 去点击淡入出只发生在静音内。两遍实测响度归一化，零削波，WAV 与 MP3 完整解码通过。

- 来源与参数：`take-v2/generation.json`、`take-v2/prompt.txt`
- 原声盲听：`take-v2/audition-listening.json`
- 最终 clips 盲听：`clips-final-listening.json`
- 精确时长、SHA 与放置建议：`clips.json`
- 最终验收：`acceptance.json`
