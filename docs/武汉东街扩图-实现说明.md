# 武汉东街扩图 · 实现与验收口径

## 空间设计

- 原晴川里主线、九位居民、六处拾光、三个风筝线索和现有车辆坐标不迁移。
- 原边界 `x=-37..37 / z=-24.3..31`；扩展到 `x=-37..105 / z=-24.3..31`。
- 可活动边界面积约从 **4092㎡** 增至 **7853㎡（1.92 倍）**。这是边界面积，包含建筑占地，并非全部可行走净面积。
- 向东串联 **燕归里 → 桥影下 → 江风渡口 / 江滩街坊市集**，新增约 68 米纵深；全环线调查中心线约 285 米。
- 8 米宽南北两条横向道路与东侧回车路形成车辆环线，中部里分横巷提供步行捷径。保留老核心紧凑任务密度。
- 新区地面保持 `.13m` 连续高度，不以路沿或虚假台阶拦住车。沿江栏杆封闭临水边，候船旧址只在栏内观察，实际乘船仍去原码头。

## 武汉表达

本区是受武汉启发的**虚构汉口滨江片区**，不是把现实地理地标拉到一起的测绘地图：

1. **里分**：红砖与暖米色墙、窄横巷、门牌、来信箱、共用晒衣绳。
2. **过早**：方块三鲜豆皮、面窝、米酒、锅盘、竹托盘；不是只替换招牌。
3. **桥影**：可真实穿过的桁架式高架结构，桥柱避开道路。桥下最小净空 6 米。真实武汉长江大桥的公铁两用背景放在观察文字中，游戏这段不是实际桥址。
4. **轮渡**：旧候船窗、栅格票窗、船票提示板与江岸护栏，提示回原有可乘船码头。
5. **街坊市集**：有竹篮、蔬果、雨棚、路边停车位；把“顺路给邻居捎一程”的生活感放进观察内容。

新增点位是 5 个 3D 场景观察站，不自动授予主线角色记忆、不替代原三个风筝线索序列。

## 共用数据与接口

`src/wuhan-district-layout.js` 是地形/地图/车辆边界/存档/观察站的共享数据：

- `PLAYABLE_BOUNDS` / `CORE_BOUNDS`
- `isInsidePlayableBounds(x,z,margin)`
- `WUHAN_BUILDINGS` / `WUHAN_ROADS` / `WUHAN_PARKING`
- `WUHAN_DRIVE_LOOP`
- `WUHAN_DISTRICT_STOPS`
- `wuhanDistrictRegionAt()` / `nearestWuhanStop()`

`world.getWuhanDistrict()` 返回可序列化的版号、面积、建筑、道路、停车点、站点、净空及碰撞统计。

`world.getNavigation(id)` 原生识别新区站点；`world` 的 `onNear` 发出 `{ district:true, kind:'district', ... }`。雨中观察点和可选风筝探索一样暂停，雨后恢复。

## 兼容与性能

- 步行边界、汽车完整底盘扫掠、自行车扫掠、下车判断、车/自行车保存统一扩展。
- 汽车/自行车保持 `.35m` 边界余量；下车保持 `.5m` 余量。
- 旧东侧无碰撞远景民房改为有物理占地的新区建筑。
- 为打通真实通路，仅将旧东侧树由 `38,-20.5` 移至 `38,-14.7`，南路灯由 `23,23` 移至 `23,25.7`；主线坐标不变。
- 新区全部并入既有静态网格分块与阴影缓存，不加实时灯，不逐帧刷新阴影。
- 雨粒子跟随玩家覆盖新区；总览镜头在进入东区后随区域东移，不再把镜头锁回老街。
- 地图仍用 10 像素/米和原坐标原点，画布从 `800×640` 扩为 `1480×640`，没有仅放大贴图伪装扩图。
