# 江城有灯 · 原画驱动的建筑重建

## 制作标准

用户要求：先用 Image 生成建筑画面，再重建为有细节的 3D 场景；细节应以生成图为目标。原来简单的纯色体块场景已被替换。当前采用 **原画约束下的手工几何重建与 PBR 贴图**；没有把一张图片描述为已经恢复了完整真实几何，也没有使用照片平面冒充整栋房屋。

### 已建立的制作链

1. `arrival.png`：武汉江城总风格和城市气氛，作为建筑设定的视觉参考。
2. `repair-reference.png`：以总风格图为参照，生成修理铺三分之四视角的详细建筑设计。
3. 三张正立面：以建筑设计为参照，生成修理铺、早餐铺、居民院落的正交立面纹理；提示词约束窗户、门洞、招牌的位置。
4. 两张材质图集：砖、瓦、石板、抹灰、旧漆木、帆布、木材、铁，共八种材质。
5. 离线处理：裁切图集，生成颜色、近似法线和粗糙度贴图。法线与粗糙度是图像推导的艺术近似，非实物扫描数据。
6. Three.js 重建：墙体、真实门口凹进空间、开启的门扇、窗框、百叶片、窗台、石饰、屋瓦、雨棚支架、排水管、空调外机、店内工作台与灯具分别建模。
7. 场景照明：暖色方向光、环境光、实时阴影、环境遮蔽、轻微辉光、江面实时反射；近看与俯瞰两种视角。
8. 浏览器截图对照：检查比例、模型与正立面接缝、悬空片、深度、文字和可达性。

### 对照重点

- 三分之四视角能看到建筑侧墙与屋顶；旋转后仍有连续体积。
- 门扇边缘有厚度、视差和阴影；门后有室内空间，而非把门画在方盒子上。
- 百叶、窗台和管线产生视差；瓦片有重复构件和真实表面凹凸。
- 立面中文字在正常观察距离可读；招牌与角色任务对应。
- 纹理接缝和比例需审查；不同质感的资产不能再用同一种单色材质代替。
- 精致模式和流畅模式都能完整玩完；流畅模式关闭较重的阴影与后处理。

### 当前仍需继续提高的美术项目

生成图具有离线插画级的环境细节和光照，当前实时重建还不能宣称达到同等完成度。优先继续改进：人物模型与动画、地标建筑雕饰、可进入的完整室内、植被近看质量、纹理无缝程度、道具形状与布料、建筑细节的跨视角一致性。比赛发布前需要由用户/美术进行实际画面对照验收；不把“贴图已接入”记为“插画级画质已通过”。

## 角色授权素材

当前阿遥使用 `public/models/ayao.vrm`，改编自 pixiv / VRoid 提供的 **AvatarSample_A**。模型作者元数据为 `VRoid`，实际文件取自第三方免费镜像；适用 **VRoidPreset_A–Z 专用使用条件，非 CC0**。本项目进行了配色、纹理优化、动画集成，并制作独立斜挎包等配件；基础人物及服装几何不属于项目从零原创素材。

来源、免费演示/参赛包的使用方式、官方条款及分发限制见 [阿遥角色素材来源与使用条件](../public/models/AVATAR-LICENSE.md)。原始条款、本地文件哈希与构建记录保存在 `output/qa/character-art/`，尚未证明第三方镜像与官方最新导出文件版本相同。

## 失败记录

第一次结尾视频任务因供应商生成的音轨触发 `OutputAudioSensitiveContentDetected.PolicyViolation` 而失败。该任务未被接入游戏。结尾改为独立无声环境镜头，并使用单独生成的旁白音频；新任务已成功落盘。失败任务 ID 和状态仅保留在被 Git 忽略的本地工作记录中。

## 凭据与运行

用户指定的 `.env` 已复制到项目根，权限为 `0600`，并加入 Git 忽略。凭据只由离线制作工具读取；前端没有模型请求，也不读取密钥。网页构建物可独立运行，无需 `.env`。

## 本轮细化内容

- 正立面像素坐标作为建模依据，招牌、窗台、百叶和石雕构件分离；材质缓存允许同类房屋一起绘制。
- 收音机音孔与调谐面板、编织竹椅、羽状蕨叶、旧台灯；人物有衣领、口袋、围裙、制服和面部细节。
- 过早铺的柜门、五金、热干面线条与葱末芝麻，带锅沿和提手的炉子；渡船使用曲线船壳、护舷、围栏和有框窗组。
- 江汉关钟框/柱廊，大桥双层桥面与桁架，远处黄鹤楼的曲面飞檐。
- 天光环境贴图、地面反射与排水沟、梧桐落叶、探索微光、屋顶遮挡时的相机抬高。

## 复用素材制作命令

在项目根目录执行。已有同名文件会保留；要创建新素材，先增加对应的 `media/prompts/<名称>.txt`。

```bash
# 建筑正立面，以现有原画作为参考
.venv/bin/python tools/media.py image repair-facade --reference output/imagegen/repair-reference.png --size 1536x1024

# 视频首帧取自 public/media/ending.webp，提示词为 ending-video.txt
.venv/bin/python tools/media.py video ending --silent --poll

# 旁白，提示词为 letter-audio.txt；需要 ffmpeg 来生成浏览器用 MP3
.venv/bin/python tools/media.py audio letter

# 从材质图集生成浏览器纹理
.venv/bin/python tools/process_textures.py material-atlas
.venv/bin/python tools/process_textures.py detail-atlas
```

`public/media/manifest.json` 记录已经接入的影像与语音。新增片段后应先确认文件可播放，再更新该清单。制作脚本只在离线制作时读取 `.env`；前端无需配置上述模型接口。
