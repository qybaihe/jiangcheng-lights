往事沿用旧方案的轻微语速差异：外公 -4%、婆婆 -6%、蔡姨 +1%、周伯 -5%；人物基础声音不换。全部为普通话合成声音，不将韵律调节称为武汉方言、老年演员录音或声音克隆。旁白 profile 兼容保留，但这版没有擅加旁白生成任务。

- 单条 MP3，48 kHz、单声道、96 kbps。
- 目标约 -19 LUFS，留出 -2 dBTP 峰值余量。
- 新版按完整文本与完整音色参数指纹匹配旧资产；这次 **205 个版本均需新做，实际复用旧成品 0 个**，旧音频仍保留。新增结局阶段沿用已做好的 205 个 v3 版本，新增 28 个有效版本；总编修正的三句另更新 4 个男女/角色版本，过期版本保留但不进入正式清单。
- “好。”“那就好。”两个极短回应初次响度校正未达标，保留原始合成内容，通过同源有界增益与超采样限幅校正；没有加字，没有改说法，没有为了重试重新请求合成。
- 本轮新增安装的是原 `.venv` 内的 pinned Edge 客户端及依赖；继续使用能正常工作的 Python 3.13.15，没有新建其他 Python 环境。
- 工具不读取 `.env`、浏览器 cookie 或账号凭据；只发送已认可的口播文字及固定声音参数。
