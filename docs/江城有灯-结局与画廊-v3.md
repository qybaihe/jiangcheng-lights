# 江城有灯 · 四种归途与成就画廊

## 体验原则

结局不是最后一道四选一问答，而是两次日常决定与真实任务结果的组合。答应帮忙、把事情交接好、是否多留一天，都会被记住。遗憾来自错过一次饭约，不虚构伤亡，也不把独居老人当作惩罚玩家的道具。

现在时的告别和外公电话仍在 3D 场景中演出。主线过去的结尾 CG 讲述同一段真实往事，不因玩家选了不同结局而改写过去。每种结局另有一张独立横屏收藏画，以门、窗边空位、饭盒、渡船座位表达差异。

## 分支规则（制作 / 验收用，含剧透）

| 结局 | 真实条件 | 当下演出 | 收藏画意象 |
| --- | --- | --- | --- |
| 真 · 灯下有你 | 社区完成回执，选择留到明早，主动听完毛巾往事 | 原认可结尾往事 CG → 原认可外公电话 | 修理铺窗边的空位、完整童画、有人聊天的巷口 |
| 好 · 明早见 | 社区完成回执，选择留到明早，未完成毛巾支线 | 同一段过去 CG → 独立的家常电话 | 两碗热干面、四块豆皮、一张等人坐的竹凳 |
| 平常 · 顺路归来 | 选择离开，且没有尚未落实的帮助承诺 | 在 3D 中向外公告别，不播放“晚两天”的矛盾台词 | 渡船座位上的包与钥匙、窗外汉口岸线 |
| 遗憾 · 未赴的约 | 答应帮助社区，但在落实回执前离开 | 先向小许交代，再告诉蔡姨这次赶不上饭约 | 盖好的红盖饭盒、空竹凳、仍然亮着的街坊窗户 |

“社区完成”只读真实 `checked` 标记；不以收齐物资代替交付，不以看过 CG 代替办完事情。跳过视频仍可正常完成剧情，不剥夺真结局资格。

### 选择位置

1. 社区准备前：答应留下帮忙，或先看看能做什么。不阻断后续帮助。
2. 修理铺 / 码头附近：查看离开安排，经过两次确认才提前结束；第一层可取消。
3. 社区回执后返店：留到明早，或按原安排回去。离开分支不播放留下的电话。

不把“真结局条件”放进未解锁卡片，以免第一次探索变成勾选攻略；通过小许椅背上的毛巾等可见交互提供发现机会。解锁后可在画作背注查看该条归途的条件。

## 画廊

共 15 幅收藏位：4 张独立结局画、8 张过去回忆 CG、3 张成就画。

| 成就画 | 解锁 |
| --- | --- |
| 画里的人 | 完成婆婆的四片童画拼图 |
| 江城拾光 | 找到六处城市生活附页 |
| 一件一件，做到一起 | 完成社区物资、风险报告与回执 |

- 独立入口位于顶部工具栏，结局画面也可直接打开。
- 分类为全部收藏 / 四种归途 / 旧日片段 / 江城画作。
- 未解锁结局不输出图片 URL、标题或剧情描述到卡片 DOM；不是先加载图片再加模糊。
- 展开画作保持原图比例；提供重温与返回分岔点。
- 本机收藏使用独立存储键 `jiangcheng-lights-gallery-v3`，恢复分岔不清空画廊。
- 返回分岔需要再次确认，会恢复当时进度；不会悄悄替玩家做完任务。
- 旧版完成存档保留原结局收藏；新增毛巾只在真正触发支线后解锁。

## 美术连续性

- 横屏 1792 × 1008，童画为 1536 × 1536，可原比例查看。
- 饭盒固定为浅奶白长方形盒身、暗红长方形盖、角上一点掉漆。初次生成的圆饭盒已列为返修项，采用复核后的版本。
- 豆皮是金黄薄皮、糯米与丁状配料的方块，不使用锅贴形状。
- 外公健在。真结局没有遗像、祭奠或病危暗示。
- 成年主角不在独立结局画中露脸，因此不会让男性选角突然变为女性。
- 晴川里是武汉生活语汇构成的虚构街区；画廊不是城市测绘图或历史影像证据。

## 验收

1. 四个条件分别可达，提前离开不会伪造 `checked`、`ending`。
2. 好 / 真共享过去，却切换到各自正确的现在时电话；平常 / 遗憾不误播留下的台词。
3. 所有分支配音遵循原声线，男女主逐句各有对应文件；关闭语音不影响字幕和推进。
4. 解锁跨本机周目保留，刷新仍在；分岔快照不包含自身嵌套引用。
5. 未解锁图卡无剧透资源；已解锁图卡滚入视口后完成解码，不留空白。
6. 画作查看、返回、分类、键盘焦点和分岔确认均可操作。
7. 视频只在过去记忆入口播放，结束 / 跳过返回第一句现在时，不重复影片里的对白。

实际检查结果以 `output/qa/story-v3/` 的运行报告和 `media/gallery-art-v3.json` 的资产哈希为准；本文不把计划镜头数当作已交付成片数。
