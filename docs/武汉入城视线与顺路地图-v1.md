# 武汉入城视线与顺路地图 v1

## 体验目标

不是继续堆地标，而是把三个尺度连起来：**江城轮廓 → 主人公脚下的巷口 → 街坊生活与江岸往返**。

### 一、从影片回到可玩的街道

新开局序章结束或跳过后，人物留在原巷口 START。实时 3D 镜头用约 3.8 秒从江汉关、大桥的城市视野落回主角；不是新增视频，不新增传送点。镜头中的建筑就是接下来探索的同一个世界。

- 玩家按移动键、拖动视角，或点“沿巷入城”即可立即接管。
- 减少动态效果模式不播放这段运镜。
- 画面落下后沿真实导航光点走到修理铺，按 E 才接外公的电话。
- 不再“播完影片 → 传送修理铺 → 自动对话”；街巷成为真正的第一个可玩段落。
- 已有存档不挪位置，不强行重播开场；第一人称偏好不被覆盖。

### 二、让七处日常成为一条顺路

按 M 打开地图，新增“外公的顺路地图”页签。它与实景街区地图共用一个面板，不挤占地图面积。也可从“巷中生活”进入，或在修好收音机后的天气提醒里查看。

| 顺序建议 | 玩家实际行为 | 情感衔接 |
| --- | --- | --- |
| 蔡记过早 | 查看过早记忆 | 留给晚来街坊的一碗面 |
| 燕归里 | 阅读门牌字条至末页 | 忘带钥匙，可以敲隔壁 |
| 豆皮面窝摊 | 阅读旧价签至末页 | 热的先吃，零钱下次找 |
| 桥影下 | 阅读旧合影至末页 | 照片只留半张脸，陪伴却很完整 |
| 街坊市集 | 阅读竹篮故事至末页 | 三户门牌，是替别人多走几步 |
| 江风渡口旧址 | 阅读船票故事至末页 | 小孩留不住票角，大人替他收好 |
| 原老巷码头 | F 登船，完成整班近岸往返 | 回来的还是那条巷，已经认得窗里的人 |

纸页上的七站是**行程示意而非地理地图**。选择一站可同步实景地图目的地，点击引路使用已有可行走寻路系统。

### 三、不给玩家再加一份打卡任务

- 纯粹派生已有 `lore`、`wuhanVisits`、`props.ferryRides`，不加第二套存档或奖章规则。
- 六处文字记忆与一班往返船，首站沿用原有“查看即记录”语义；东街五处仍需末页确认。
- 建议次序不是硬门槛，可乱序探索；路过、地图选择、提前下船不额外记为完成。
- 完成当前站后只建议下一站，**不自动行走、不悄悄改换方向箭头**。
- 主动开启时才出现窄纸条 HUD；可以收起、回主线。
- 原主线任务变化、选择其他目的地或追踪风筝，都让当前导航按玩家的新意图接管。
- 晚间预警时漫游让位于社区安排，沿用码头已有的暂停与确认复航状态。
- 重看已完成地点走普通单点引路，不伪造新的完成进度。
- 临时点击街坊走近时，小地图与地面光点共同切到那位街坊；任何明确重选目的地、收起或回主线，都会取消旧的临时接近，避免临到身边又误弹对话。
- 顺路模式返回标题后，继续游戏恢复主线指引；原先普通的单点导航仍沿用原有继续规则。

## 保持不变

人物、旧对白与 TTS、CG 文件、原有四结局、旧图解锁、车辆、主线任务条件及空间坐标均保留。晴川里仍是武汉生活意象构成的虚构街区；江汉关和大桥是远景，不宣称开放建筑内部游览。

## 验收重点

1. 新开局自然播放、跳过与 reduced 三种入口，均保留原位置与未领取委托状态。
2. 入城镜头实际看见 3D 地标；移动/看向/菜单立即打断；后台不偷跑，resize 不重播。
3. 手动走到修理铺 E 交谈后，原收音机—街坊—应急—结局链路不变。
4. 1440×900、1280×720 的双地图页签和 HUD 不遮挡主角、导航与位置字幕。
5. 七站既有记录正确派生，完成不自动续走，收起/回主线/预警具有单一明确导航目标。
6. 全屏/Esc、男女主角、居民对白和语音连续性不回归。
