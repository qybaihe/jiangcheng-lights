# 《江城有灯》本轮整体验收记录

日期：2026-09-08。对应 [参赛统筹方案](参赛统筹方案.md)，本记录区分已实现、自动化通过、实际画面检查和仍需真人／真机验证的项目。前期记录留在 [早期验收记录](验收记录.md)，不会用旧结果覆盖新失败。

## 本轮交付范围

- 剧情：三段旧物记忆分别推进“发现难处、接受回馈、有人陪伴”，重开修理铺的答案留在结尾。三位居民可乱序访问；领奖与推进有前置条件，重复互动不重复发放。
- 状态：领取、物资去向、居民对白、任务目标和手账共用进度。雨后回访有对应回复；物资领取后消失，热食打包箱从摊位转到社区。前台真实游玩耗时与运动帧增量分开记录。
- 探索：真实眼位的第一人称、街巷和全景可切换；普通对白保留3D，真正的往事进入2D，退出恢复原位置与朝向。
- 找路：按实际建筑与通道绘制的地图支持缩放、拖动、选点和定位；地图、迷你地图、地面光点和下一转弯提示使用相同路径。手动引路与自动步行分开，碰到街坊可以绕行。
- 画面与生活：天空、墙灰、植被、人物与UI提亮，四位居民有不同动作，路人停留与礼让；远处地标补上连续岸地。静态阴影按需缓存，人物使用跟脚接触阴影。

这里的“已实现”不代表离线原画等质、全部动画精修或比赛最终门槛已经通过。

## 实走中发现并修复的问题

1. 蔡姨对话机位可能被路灯灯头大面积遮挡。只检查角色投影点不足以发现；已补充灯头、灯杆和相机安全距离，并检查实际截图。
2. 自动行走被街坊挡住后，重新寻路可能再次穿过同一人的位置，形成停滞。已保留近处人物边界、允许从重叠边缘离开，并复测婆婆及电池点到蔡姨的行走。
3. 未接委托、已取物资和避雨后的地点仍可能使用通用的“领取／交谈”提示。已统一地点状态文案，与执行条件一致。
4. 手账提前写成“名单已带回、居民已平安”，以及雨后仍说雨前的话。已改为按准备、待交付和已核对三个阶段表达。
5. 慢设备的运动增量被限制时，游玩时长也随之少计。已改为记录前台真实经过的时间；旧存档不补造历史里程碑时间。
6. 生产截图发现地面宽斜纹。底层与街区铺地同高，主巷和横巷也存在重叠。已调整高度与相交几何，并修复合批与缓存时丢失投影标记的问题；正常精致画质的同机位图已确认斜纹消失。
7. 手机尺寸下，交互按钮与迷你地图、上方向键局部重叠。已将交互按钮上移至引路提示与移动控件之间；附近有交互目标时收起重复的地点说明，保留任务和地图。

全局检查首次尝试中的手账断言也未通过：测试预先写入的结局夹具，被离页时的正常自动存档覆盖。已把夹具安装移至下一页面初始化，并增加“确实处于结局”和四位街坊的正向文案断言。旧报告与截图保留于 `output/qa/global/first-integration-failure/`；其中“雨后回访通过”因缺少有效结局前提而作废，必须以修正后的复验为准。

失败报告和旧截图继续保留，不能只凭成功截图推断全部站位、设备和天气均已通过。
