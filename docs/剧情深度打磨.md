# 《江城有灯》剧情深度打磨与呈现契约

版本：2026-09-10 / story-v2。正文与状态以 `src/story.js` 为准，时间层与 CG 选择以 `src/dialogue-presentation.js` 为准，人物外形与图像提示词见《人物与CG美术设定》。本文记录已写入代码的剧情，以及整合版仍需完成的视觉和真人试玩验收，不表示素材已经生成。

## 1. 故事要留下什么

阿遥回武汉替外公送还三件旧物，原本把这一趟理解成“回来帮忙”。走完巷子才发现，自己记忆里那些普通的饭、午睡和写作业的晚上，是许多人共同照顾出来的。故事的落点不是还清人情，也不是立刻留下接班，而是知道自己不必先把日子一个人过好，才可以回来敲门。

外公健在，正在外地的姨妈家休养。开场给出剥橘子的近照，结尾由外公当下发来的语音回应，不使用遗书、诀别、病危或死亡反转。过去曾有漏雨、受潮、开不了店的难处，但不指定真实灾年，不以灾难场面制造煽情。

阿遥使用“你”“阿遥”“孩子”称呼；男女头像只是外观选择，正文与家人关系一致。童年画面约在十五年前，主角约十岁，用中性短发、普通宽松童装和背侧角度；不能把两个成年选角画成一对兄妹。

## 4. 现在时必须留在 3D

每一句正式正文都带稳定 `id`、`time`，人物发言另带 `portrait`。现在时为 `time: 'present'`，明确往事为 `time: 'memory'`；不能从对白措辞、角色是否年轻或数组的固定下标猜测时间层。

`presentationFor(sceneKey, lineIndex, {replay})` 返回 `{memory, title, placeId, cgId}`：

- 现场问候、收音机归还、物资交接、名单核对、观察报告、结尾外公语音都使用 3D 场景；手账重播遵守同一规则。
- 只有标为往事的台词才显示 CG。每段往事用旁白、稳定句 ID 和第一张 CG 明确进入；结束后必须有明确的现在时台词。
- 同一连续往事里，后续未标 CG 的台词沿用最近一张 CG；遇到现在时立即清除，不能把上一段回忆图带进新对话。
- 选择头像、展示人物肖像或点击重播都不能把整场对话改成 2D。旁白没有人物肖像，不伪造发言角色。

当前导出的 `MEMORY_BOUNDARIES` 是从时间标记派生的兼容信息，起止为零基下标且右端不包含：

## 6. 两盏灯及其他连续性

**A 灯**属于蔡姨：绿边、有提手的便携电池灯；她初摆摊时由外公送用，当下修好后已经归还过早铺。**B 灯**始终留在修理铺：铜色圆底座、细弯颈、无提手的小台灯，童年照作业，结尾仍在桌上。蔡姨回忆明确说店里另有铜座台灯，结尾再次说明 A 已还、现在亮的是 B。两者不能合成同一盏，没有明火。

红盖饭盒盖角的白色烫痕连接童年饭食与当下认物；蓝布连接开场打瞌睡、结尾作业与今日重新铺桌；折角船票连接江上生活与周伯记得的孩子；托箱与交信封都先等对方接稳。这些是可在画面里核对的回扣，不需要额外旁白解释象征。

## 7. 武汉感与应急行动顺序

武汉来自生活与空间共同指认：江汉关钟声、热干面芝麻酱与葱花、豆皮、轮渡与折角船票、长江大桥钢桁架轮廓、红砖里分、天井、竹床和蒲扇。晴川里是原创汉口老巷，压缩的地理不作现实导航；不把武昌的户部巷搬进汉口，不给虚构水痕贴上真实灾年的标签。

主线保留以下完整因果顺序：

1. 和蔡姨确认主人已同意的物资领取安排。
2. 取齐三件物资，实际返回蔡姨处逐件核对、完成交付。
3. 三家安排汇合到社区，核对应急包；“已准备”仍不等于“已送达”。
4. 玩家只从干燥主路、安全距离观察两处风险；不靠水边，不涉水，不碰电气设备，不自行搬物或维修，看不清可以说明看不清。
5. 观察后回社区报告，小许核实位置并联系相关人员。
6. 小许明确核对婆婆与陈姐到达室内、热食送到、周伯报平安，再安排阿遥安全回店。

个人药物由本人依自身需要准备，不替别人服药。关照对象有自己的选择与安排，不把老人写成需要主角任意搬运的任务道具；专业后续由对应人员负责。

## 8. 验收与容量边界

自动回归覆盖状态前置、六种邻里顺序、物资领取与交付区别、两种风险观察顺序、报告与结尾不可跳过；还覆盖稳定句 ID、男女兼容、外公健在、八张 CG 的先后、现在/过去分段、文本润色与插句后的边界稳定、重播不强制 CG、未知/越界查询不继承旧图，以及早期自由探索不泄露重开店。
