# 江城有灯 · 实际验收记录

验收日期：2026-09-08。验收对象：本地 Three.js 可玩 Demo，桌面浏览器为主要平台。

这是本次实现的实测记录。目标标准见《设计与验收.md》；未完成的人工检查不视为通过。

## 当前结论

已有可操作的完整主线，包含修理收音机、相片排序、搜寻三件物资、三段旧物回忆、应急包与两处风险辨识、返家揭示与六项武汉城市拾光。两段短视频、开场旁白和外公语音均已制作为本地素材。

当下对白现保留在可旋转观察的实时 3D 场景中，角色原地相向、镜头靠近。三段往事才切换插画，回忆后的回应自动回到同一处街景。手账仍可完整回看已解锁片段。

本轮重点完成了原画参照下的三维场景重建：三类房屋不再是纯色方块；门窗有洞口、墙厚、凹进和浮雕，屋面有几何瓦片，道具有可近看的细节。角色、江汉关风格钟楼、武汉长江大桥风格桥体和黄鹤楼剪影也已替换为较细模型。实时画面仍未按“与离线生成插画等质”验收通过。

## 已发现并修正的问题

1. 自动步行在建筑拐角提前转向，可能停在墙边。现在逐个精确到达网格路点，再转向；保温箱、饮水、电池、早餐铺路线已回归通过。
2. 地图城市拾光点只有小圆点和文字，二者之间的空隙不能点击。现在增加透明点击范围，保持所有标记可用键盘选择。
3. 生成立面与人工窗框不一致，导致窗框遮挡招牌。已按三张正立面测量位置重新开洞和建模。
4. 屋瓦朝向、屋檐背面和侧墙贴图重复存在错误。已修正面朝向、封边和墙体 UV。
5. 林婆婆院落的默认镜头可能被前景屋顶挡住。新增按建筑高度检查遮挡并抬高镜头，仍保留手动旋转。
6. 场景深浅变化导致 HUD 阅读困难。标题栏、地点提示与章节进度增加稳定的对比背景。
7. 雨后窗光材料未注册。现已接入天气状态更新；同类窗灯同时渐亮。
8. 结尾与序章短片循环会打断镜头节奏。现在播放后保留最后一帧，旁白可继续，用户可自行重播或返回。
9. 地图导航会走到 NPC 的中心，角色互相重叠。现在选择可行走的邻近位置停下。
10. 手机标题因英文副标题挤压变成三行。现在固定中文两行结构并调整副标题宽度。
11. 配电箱风险点的观察位置原来与积水重叠。现将积水与安全观察位分开，并阻止走进积水；街坊确认到达室内后，在雨中回家一段暂不显示户外人物。

12. 普通交谈原先会直接盖上整屏插画。现按对白内容区分当下与回忆，进入/返回按钮明确说明切换，并在当前街区构图。
13. 首次对话焦点落在“暂时离开”，按 Enter 会退出。现默认聚焦“下一句”。镜头恢复期间暂停常规跟随与自动抬高，结束后继续探索。
14. 菜单牌可能挡住人物脸。现缩小并固定到早餐摊雨棚边缘；对话取景考虑建筑、雨棚和招牌，手动旋转遇遮挡时保留上一个无遮挡角度。
15. 街坊进入安全室内后，重复拜访不再与隐藏人物交谈；阿遥在 3D 场景中确认去向，并提醒自己返回修理铺。

16. 侧面接近早餐摊时能走进柜体。已为大件家具添加与模型一致的行走碰撞，地图导航绕行；验证截图中的测试站位也必须位于可行走区域。

17. 手机自动取景可能把两人排成前后，并被树冠遮住。取景候选补齐两侧角度，优先横向分离，必要时提高镜头；树冠采用实际实例网格包围盒参与视线检查。失败截图与人工判定保留，投影通过但真实遮挡的一轮未标记视觉通过。

第一次通关发现路线问题；第二次到达结局后发现地图点击问题。这两轮失败记录分别保留在 `output/qa/first-pass/` 和 `output/qa/second-pass/`，不删除失败证据。

## 视觉核对与性能边界

生成图 `output/imagegen/repair-reference.png` 是建筑美术目标；实机近景 `output/qa/14-shop-atmosphere.png` 和全景 `15-street-overview.png` 是真实浏览器渲染，两者不能互相替代。

当前采用生成立面和材质图、手工建模、局部凹进与浮雕重建。深处室内仍含图像层；这不是摄影测量或自动神经三维重建。人物为微缩风格，地标为经过比例压缩的艺术模型，植被和街道细部仍有继续提高的空间。

性能样本来自 Apple M3 Pro / 独立 headless Chrome / 1600×1000，采样时应用内预览暂停在标题页。精致模式修理铺近景 80.5 FPS、全景 75.1 FPS；流畅模式相应为 120 / 120 FPS。两档使用相同的近景与全景视角，原始帧时间和 GPU 见 `visual-performance.json`；仅代表这台设备与本次条件，不等同于手机帧率。人物保留原几何与颜色，合并为每人 3 次绘制；标题与整屏回忆下暂停被覆盖的 3D 渲染。

绘制调用与三角形为整帧所有渲染过程之和，包含水面反射、阴影和后处理，不是独立模型数量。手机社区东侧因窄巷和树冠采用较高视角，人像较小但头、身、脚完整可见；桌面仍是主验收平台。

## 尚待正式验收

- **至少 15 分钟的首次主线体验**：现有主体剧本 4,174 字 / 139 句，另有谜题、现场搜寻、风险选项与城市见闻；目标 18—25 分钟。尚无 3 名首次玩家的真人测时，因此 ≥15 分钟不得标为已通过。
- **武汉辨识度盲测**：场景有钟楼、大桥、轮渡、过早、汉口老街特征；仍需按基线找熟悉武汉的测试者，不显示标题进行截图辨识。
- **应急内容的专业核验**：现有内容围绕提前准备、避免涉水和电气危险、及时上报，无专业核验完成记录。
- **画质达到原画目标**：门窗、屋瓦、道具已有明显细化；完整可进入室内、植被、人物动画、街道生活密度和多角度画面一致性仍需艺术评审。
- **更多硬件**：普通集成显卡、安卓与 iOS 真机性能未验收。手机页面排版检查不能替代真机性能检查。
