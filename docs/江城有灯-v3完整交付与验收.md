## 2. 四种归途，不是结尾的一道选择题

结局由此前的帮助承诺、实际社区回执、是否留下过早、是否主动了解小许的毛巾往事共同决定。现在时的告别和电话都发生在 3D 世界中。

| 结局 | 情绪落点 | 对应收藏画 |
| --- | --- | --- |
| 真结局 · 灯下有你 | 从替外公办事，到发现自己也一直被照顾着 | 窗边空位、完整童画、巷口聊天的人 |
| 好结局 · 明早见 | 没有问完所有往事，也可以约好下一顿过早 | 两碗热干面、方块豆皮、等人坐的竹凳 |
| 平常结局 · 顺路归来 | 这次先回去，仍有下一次回来 | 渡船上的包、钥匙、汉口岸线 |
| 遗憾结局 · 未赴的约 | 答应帮忙后提前离开，错过一顿留好的饭 | 盖好的红盖饭盒、空凳、街坊仍亮着的窗 |

遗憾不是虚构伤亡或灾难惩罚。外公健在；不同选择改变当下，不改写过去。真 / 好结局共享同一段历史影片，之后接各自的现在时电话；平常 / 遗憾使用各自的 3D 告别。**四个结局各有独立 CG 插画，不是四部不同的结尾影片。**

制作验收所需的准确条件见[结局与画廊说明](/Users/baihe/Documents/ChatGPT/腾讯云游戏开发大赛/docs/江城有灯-结局与画廊-v3.md)。未解锁的画廊卡片不展示这些剧透。

## 5. 配音、配乐与环境声

- **169 句口播 / 233 个音频版本**；成年阿遥 64 句有男女两版。
- 固定角色音色与自然语速；保留用户认可的短对白，没有重新添加解释性旁白。
- 实际供应链为既有 Edge neural Read Aloud / `edge-tts 7.2.8`，普通话合成声。
- 233 个文件完整解码、文本与文件哈希、男女覆盖、响度和峰值均完成核验。响度为 −20.88 至 −18.51 LUFS，最大真峰值 −2.06 dBTP。

- 五部混音版都经过绑定实际混音哈希的模型辅助听审，未发现遮蔽、截句或额外人声。
