## 1. 一条有起伏的宣传线，而不是功能点名

**回武汉 → 为一个人停下来 → 把路走远一点 → 在江风里玩一圈 → 回来照应街坊 → 选择留下哪一种回忆。**

前 34 秒让观众认识“人”和返乡缘由；中段 40 秒打开城市空间、交通和冒险；后 27 秒收回到互助、结局、画廊。随后用 8 秒证明 AI 如何参与制作，最后 9 秒留给一盏有人替你亮着的灯。

- **武汉贯穿行动**：里分中的门牌和街坊、蔡记过早、轮渡的旧票、桥影和江上视线分别落在真实可玩的场景里。不只在片头写“武汉”，随后拍通用小镇。
- **车和船让关系延伸，不冲淡关系**：去远一点的地方，遇到街坊，再停下来。计时赛是约定，不是抢救倒计时，不因竞速代替社区准备。
- **可玩证据优先**：每一种主打交互至少留一组“输入 → 反馈”。不剪成手伸过去就自动成功的伪玩法。
- **不靠密集配音填满**：阿遥与街坊的短句、铃声、桨声和江风交替。高潮不靠喊口号，而在“人和饭都到了”那一句停下来。
- **四结局是不同的归途**：展示正常选择与已完成记录，不暗示小游戏成绩决定真结局。纪念画会留下走过的路，而不是强迫全收集。

### 节奏红线

1. 不用强行 2 倍加速取代内容取舍。真实驾船转向至少连续 4 秒；竞速是剪去途中空程，不让 50 秒的完整一圈看起来只用 5 秒。
2. 保留游戏计时器的实际数值，切点跳跃可见；计时赛持续标注“过程有剪辑”。不把数字重写成宣传效果。
3. 14 秒互助段只精选节点，不用快闪字幕读完 11 步。原片需完整保留三件物资、两处风险与社区回执，以便验收。
4. 四结局总览至少 2.5 秒；画廊至少停住一幅图 3 秒。若实拍信息仍过密，先减少自驾空镜，不压短关键反馈。

## 3. 真实故事与武汉口径

### 主线因果

- 外公健在，在姨妈家休养；主角阿遥回家替他送东西，不是处理遗物。
- 修的是收音机。蔡姨旧灯是归还物；周伯手电是已经修好的委托物；结尾铜座灯是童年意象。字幕不用笼统“修灯”代替三种物件。
- 三家拜访允许自由顺序。本片选婆婆 → 蔡姨 → 周伯作为清楚的观看路线，不宣称游戏强制这样走。
- `chefRequested` → 领保温箱 / 饮水 / 电池 → 回蔡姨交付，收齐不代表社区已收到。
- `prepared` → 两处风险报告 → `checked`，只有最终回执能说“人和饭都到了”。玩家观察、报告、配合，不演成一个人处置洪水。
- 计时赛安排在晚间预警生效前；雨后复开必须以正式游戏开放条件为准。玩赛车或划船不会跳过应急准备。
- 四结局由主线、支线和去留决定。先拍实际分支，再写角标；普通留下结局不标成真结局。

### 武汉不是地标清单

| 线索 | 放在什么行动中 | 必须保持的区别 |
|---|---|---|
| 里分 / 里份 | 寻人、骑车、穿支巷进院子 | 晴川里和燕归里是虚构地点，不冒称某处文保街区复原。 |
| 过早、豆皮、面窝 | 蔡姨的招呼、物资交接、顺路赛的生活对白 | 让锅气和称呼自然出现；不是全体 NPC 同一句武汉口头禅。 |
| 江汉关与轮渡 | 返乡视线、旧票、江上望岸 | CG 与实机航行分别标注；原自动渡船和新可控桨舟分开。 |
| 武汉长江大桥意象 | 开车望桥、桥影下旧合影、划船时的水面反射 | 真实长江大桥连接武昌与汉阳；游戏桥影是艺术化呼应，不写成汉口真实桥址。 |

### 混音

- CG 原画、环境、角色、宣传旁白、BGM 分层，不叠用已经混完的预览音轨。
- 角色说话时宣传旁白让开；社区回执和结尾各留安静的完整句。
- 车速声、桨入水、浮标反馈与实际操作同步，不用同一个夸张“成功”音套所有事件。
- 目标约 -16 LUFS、真峰值不高于 -1 dBTP；实际先听自然度与对白清晰度，再核数字。保留至少 25 秒不出现宣传旁白的呼吸空间。

### 字幕三层

1. **来源**：CG 全段 `Seedance 叙事 CG` 或 `Seedance 回忆 CG · 童年往事`；游戏段 `游戏实机 · 过程有剪辑`；AI 证据段 `AI 参与制作 · 非实时玩法`。来源互斥，不混标。
2. **行动**：每次只说明“去哪 / 找谁 / 做什么”，一到两行，单行约 12–22 字。车辆段用清楚动词，故事段用具体人物。
3. **人声**：逐句按真实波形对齐，不逐字跳动。正式游戏本来已有角色字幕时不再叠一份全文，只保留小任务注。

1080p 画面安全边距 ≥64px。手账 / 成绩卡 / 游戏字幕 / 中央角色和下一道检查点都需避让。逐镜根据画面留白放字，不全片套同一个底部大黑条。四结局总览与画廊段减少外加字幕，让实际界面说话。
