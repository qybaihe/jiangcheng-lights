# 《江城有灯》人物与 CG 美术设定

版本：2026-09-10 / story-v2。本文是本轮静态人物肖像与八张关键 CG 的制作依据，已与新版剧情节点对齐。提示词草案已落盘，不代表图像已经生成或验收。本文不规划或提交视频。

## 1. 观众应该看见的人与城市

一个人回到武汉，慢慢发现自己从小被很多人照顾过。画面以具体动作建立关系：一盒先盛好的饭、一把赶蚊的蒲扇、有人愿意接住工具箱的一边。外公当下健在，在姨妈家休养，结尾会发来即时语音、约回来吃饭。温情不依赖哭泣、死亡暗示、病床、洪灾或废墟。

统一画风为 **精致、明亮、温暖的中国都市生活动漫**：人物面部明确使用干净细线与平涂色块，2–3层柔和赛璐璐明暗，老人皱纹以少量短线表达；禁止毛孔、摄影级肤色渐变、油亮皮肤和写实肖像脸。建筑和生活用品用有结构的动画电影背景。不是写真、塑料 3D 玩具、日式小镇、校园恋爱海报，也不套整幅棕黄滤镜。棉布、针织、搪瓷、木材和砖面各有可辨质地，背景细节不能吞没人物动作。

阿遥男/女两款沿用已经实装的造型，不能退回旧提示词中的长发或低马尾。女款参考 [现有肖像](../public/models/ayao-female.webp)，男款参考 [现有肖像](../public/models/ayao-male.webp)。基础造型来自获许可改编的 VRoid AvatarSample_A / C；人物故事与项目配件另有创作来源，不能把基础模型说成从零原创，见 [模型授权说明](../public/models/AVATAR-LICENSE.md)。

## 3. 每个人怎样动，才像同一个人

- **阿遥**：先看、再问，做事时会轻扶包带；肩膀从返乡时的微紧变得松下来。成年男女气质相同，不把男款画成逞强英雄、女款画成被动照顾者。
- **外公**：手艺人的动作小、准，常把布或工具放整齐；想说“我来”时肩背先绷一下，接受帮助时会停住手、抬眼听人讲话。十五年前背较直、黑发更多，脸骨、眉尾、鼻子不变。当下有精力交流，不以病容说明休养。
- **林婆婆**：眼睛先笑，手会把饭碗或毛巾往对方方便拿的位置移；说话不必一直笑。她有判断、有自己的安排，不画成迷糊无助的孤苦老人。老年变化来自眼睑、颈部、手背与发色，而不是脸上几条符号线。
- **蔡姨**：站得稳，动作利落，先把东西放稳再招呼人；半句话就能让拘谨的人坐下。保持生活里的结实身材，不用肥胖或大嗓门做性格标签。
- **周伯**：不抢人手里的东西，先对视、得到回应才接工具箱的一边；杯子稳稳端着。宽肩和平眉与外公窄脸形成区别，不做威严站岗的制服形象。
- **小许**：核完一个名字再抬头；疲惫时按住纸张、放下笔，而不是崩溃哭泣。被婆婆递毛巾时，肩颈稍松，意识到自己也可以接受照顾。

肖像统一 1024×1536、2:3、从完整头顶至大腿中部、浅暖米灰底。奶油色左前上光、灰玉绿补光；头顶留约 7%，双手与专属物件不被裁切。除非未来另做表情图集，主肖像只保留浅笑或认真聆听的中性表情。不要生成姓名、边框、说明字或机构标志。

## 5. 武汉必须来自空间和生活

晴川里是原创的汉口街区，使用里分建筑语言：二三层相连砖屋、红砖与灰抹面并置、分段砖拱/浅拱、石或灰泥门楣、木百叶、狭长门洞、天井、外廊和公共通道。配植物、竹床、竹凳、搪瓷盆、晾衣、旧脚踏车与早餐用具；不要用白墙黛瓦水乡、纸灯笼、鸟居、樱花、日式电车或木温泉旅馆替代武汉。

武汉线索分层，不在每幅画里堆齐地标：

- `granny-table`、`chef-lamp`：热干面与汉口里分院落/过早摊。热干面是芝麻酱干拌面，少量葱花，不是日式汤拉面；豆皮可作小份背景食物，不能画成寿司。
- `granny-bamboo`：江城夏日的竹床、蒲扇、院落通风与邻里照看，比旅行海报更有生活识别度。
- `dock-shared-box`：宽阔长江、白蓝渡船、岸内侧干燥公共通道；单独呈现武汉长江大桥的方整石质桥头堡、低平连续钢桁架和公铁双层关系。桥跨龟山与蛇山之间，不画成悬索、斜拉或红色金门桥。
- 江汉关属于汉口沿江，采用浅石色古典主体、高耸方形钟楼和正确钟面层次；若需要额外城市建立图，再单独以它为主，不强塞进码头 CG 与大桥同一背景。本轮八图无需牺牲构图来凑全地标。
- 黄鹤楼属于武昌远岸，户部巷也不在汉口。不能把它们与江汉关排在同一条里分巷里。本轮不新增黄鹤楼近景。

地理可以为虚构游戏压缩，但保留近巷/近岸、开阔江面、远岸的层次；不把构图称为真实机位、航线或精确历史复原。昼夜光照与天气服务剧情：童年竹床回忆是晴热午后，初摆摊是清晨，码头是干燥傍晚，小许是一年前雨夜的安全室内；不能把八图全部变成暴雨。

## 6. 八张 CG 的确定内容

## 7. 提示词、参考与制作顺序

正式 runner 读取平目录；全部 prompt 在 `media/prompts/`：

- `story-v2-portrait-{female,male,grandfather,granny,chef,dock,xu}.txt`
- `story-v2-cg-{granny-table,granny-bamboo,chef-lamp,chef-extra-bowl,dock-shared-box,xu-first-shift,ending-reopen,ending-lamplit-child}.txt`

先出七张当前肖像并检查脸、年龄与衣服，再将合格肖像作为 CG 人物参考；不能给每张 CG 只重复一段文字、让模型重新发明人物。每个输入标清对应角色和用途，画面可以换光、换角度、变年龄，脸骨、发际线与专属配色不能随镜头漂移。

CG 建议顺序：`granny-table` 验证双人互动 → `granny-bamboo` 固定童年形象 → `chef-lamp` → `chef-extra-bowl` → `dock-shared-box` → `xu-first-shift` → `ending-reopen` → `ending-lamplit-child`。四人结尾在前面各脸稳定后才做。低模 NPC 截图只提供轮廓与配色；它们不能压过新肖像的成人年龄和精细五官。

执行方已选阿遥女款成稿 `output/imagegen/story-v2-portrait-female.png` 为全组动画风格参考。附给其他人的时候只取细线、平涂与色彩，不能复制她的脸、年龄、衣服或把她画进 CG。外公第一张偏写实，CG 应使用回到动漫风的 `story-v2-portrait-grandfather-r2.png` 定稿；若后续采用更新重绘，再更新逻辑主参考，不继续引用旧脸。

## 8. 验收门槛

1. **角色**：七张当前肖像年龄和发型正确；同一人跨年代能靠脸骨、眉鼻、发际线、配色和物件认出。男/女阿遥都与现有选角图相符，童年图不与其中一个存档冲突。
2. **剧情**：外公健在；前六张不出现集体重开门；小许只早一年；结尾两个画面互补，不重复亮灯，也不呈现死亡或诀别。
3. **动作**：无多肢、手指融合、空握、穿模、浮碗、倾斜悬空工具箱。推碗有桌面接触，托箱有重量，递毛巾有清楚的持握，孩子自然睡或写字。
4. **物品**：A 绿边提灯和 B 铜座台灯明显不同；厨房图红盖小饭盒、盖角白点、葱另放，孩子未到场；旧照与早期童年轮渡照片不同；无无故增减的道具。
5. **武汉**：热干面、里分、竹床、轮渡与大桥至少形成两类独立线索；大桥为钢桁架、公铁双层，不乱拼江汉关、黄鹤楼、户部巷的岸别。
6. **生活可信**：人站干燥安全通道，社区室内干燥；无涉水碰电、洪水搬箱、抢险英雄化、灾民营或虚构真实名单。纸面无需模型生成可读文字。
7. **视觉**：有前中后景、材料区别与自然光色；人物脸手不被字幕安全区遮住。肖像源图 2:3、CG 源图 3:2 并留16:9裁切安全区，检查实际像素而不只看文件名。整张图及脸/手/道具局部都看原尺寸。
8. **交付诚实**：提示词、输入参考、实际输出规格、修订与人工检查分开记录；未生成的图不写进已完成清单，未进游戏不宣称接入完成。人物、场景与应急情境的正式试玩仍由整合版本验证。
