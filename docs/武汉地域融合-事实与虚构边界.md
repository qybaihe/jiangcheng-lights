# 《江城有灯》武汉地域融合：事实与虚构边界

核对日期：2026-09-12。范围：新增五处观察站、对应新区场景、关联的六类江城记忆题材。本次只读核对，不修改运行源码。

## 结论

**新增五站没有查出明确的基础事实硬错误。**“武汉长江大桥 1957 年通车、属于公铁两用桥”“武汉人把吃早餐称为过早”“里分/里份的联排民居属性”“轮渡承担过江通勤”“江汉关钟声进入居民日常”都有可直接读取的官方或中央媒体来源。

最需要守住的表达边界：**武汉长江大桥实际连接武昌与汉阳，不是汉口里分街区里的一座本地高架桥。**游戏新增桥影必须保持“桁架结构的艺术化呼应”身份。现有观察文字已经说明“并非真实桥址”，应在地图、宣传片与参赛说明中保持同一口径。

## 二、可复核来源

### [1] 通车时间与公铁两用

- 武汉市政府转载长江日报，**《防撞主动预警，武汉长江大桥成功套上“金钟罩”》**，2023-12-09。

### [2] 真实大桥位置

- 武汉市政府，**《生日快乐！武汉长江大桥67岁了，全国游客解锁“游桥”新方式》**，2024-10-15。

### [3] 里份/里分定义

- 湖北省文化和旅游厅，来源《湖北方志》，**《武汉老里份》**，页面发布日期 2015-05-12。

### [5] “过早”不是“时间过早”

- 武汉市政府，来源长江日报，**《一份难得的武汉市民街头过早习俗影像——张建忠纪实摄影展即将开幕》**，2022-06-24。

- 用法：摊边熟客称呼、盛面手势、锅气、共享小桌，比将所有角色都塞入同一个口头禅自然。

### [6] 豆皮与面窝的食物身份

- 湖北省文化和旅游厅，**《武汉十大美食》**，2023-12-01。
- [官方页面](https://wlt.hubei.gov.cn/bmdt/ztzl/zcwdk/ywzsk/ly/202312/t20231201_4982778.shtml)
- 支持：武汉豆皮的皮由绿豆、米浆制成，馅以糯米为基础；三鲜配料有不同组合。面窝是大米、黄豆米浆在铁勺中油炸的中空圆形米饼。
- 画面验收：豆皮表现为金黄表皮和糯米馅的切块，不当作普通豆腐皮；面窝保留油炸米饼的不规则薄脆边缘，不加甜甜圈的糖霜/糖粒。代码中的圆环模型是造型简化，并非已完成食物微观复原。
- 文案“有人爱面窝配米酒”表达个人偏好，没有宣称唯一标准搭配，可以保留。

## 三、已明确的创作边界

### 空间

- 晴川里、燕归里、江风渡口、街坊市集和两条游戏道路为虚构组合。
- 1480×640 的游戏地图是世界坐标示意，非武汉城市交通图。
- 新区宽路服务驾驶；里分内部保留窄巷与生活空间。8 米车道不是对所有老里分街巷历史宽度的断言。
- “晴川”是本作地名意象，新增汉口式街区不因这个名字就等同现实汉阳晴川阁片区。
- 大桥、江汉关、里分、轮渡不必同时挤入每张图片；每个画面只让一个空间逻辑做主。

### 人物与事件

- 外公、阿遥、林婆婆、蔡姨、周伯、小许和其他居民为本作人物。
- 借灯、带早餐、票角、竹篮、合影、干毛巾等为编剧创作，未被包装成有档案证明的武汉历史事件。
- 年轻小许的初次值班属于近年的个人回忆，不与上世纪老照片一概套同一年代。
- 老照片处理是美术形式，不是素材的史料来源声明；生成图也不署“武汉某年实拍”。

### 细节与串联建议（不属于事实阻断）

1. 新“竹篮”站关联 `lore-photo`，而该旧记忆是轮渡合影：关系目前偏弱。作为“回老铺看看合影”的线索可以成立；不应在呈现上把轮渡图说成竹篮故事的直接现场照片。
2. 新过早站以豆皮和面窝为主，关联 `lore-noodles` 热干面回忆：可用“这味道让我想起蔡姨”的过渡，不把食物名称混为一谈。
3. 桥影站的家庭合影与 `lore-bridge` 船窗数桥影是相关的两次观察，不应一口气暗示同一张照片、同一拍摄地点。
4. 里分是建筑和居住组织，不等于所有房子都破旧、昏暗、贫困。明亮青绿树影、暖砖和有秩序的生活细节与事实不冲突。
