# 武汉记忆插图 · v1 接入说明

每个已编排的记忆节点对应一张独立横屏插图。共 44 张：8 张主线、27 张街坊、6 张拾光、3 张探索。图片不替代 3D 中眼前的街坊；初始只露出右侧相册页，玩家主动点击才细看。

## 视觉与时间线

- 青绿、暖米白、浅杏光和温润红砖延续游戏画风；旧意来自轻微褪色、纸纤维、细颗粒，而非重褐色滤镜。
- 阿遥童年的插图使用中性短发儿童形象，与男女主角选择兼容。
- 小许始终为年轻女性，她初到社区的回忆发生在近年；不放进几十年前的画面。
- 陆师傅是暂时外地休养的外公，不改写为已故。
- 晴川里及个人旧事为虚构，武汉元素采用轮渡、里分、竹床、热干面、豆皮、面窝、江汉关钟声、长江大桥钢桁架；不把所有地标硬拼在一张画里。

## 接入

- 数据：`src/wuhan-memories.js`。生成计划：`media/wuhan-memory-art-v1.json`。
- 统一 UI：`src/ui/memory-art.js` / `src/ui/memory-art.css`。`memoryCardMarkup(id, { placement, collected })` 生成卡片；`mountMemoryInspection(root)` 负责主动检视、Escape 收图、错误降级和销毁。
- 居民聊天：话题第一句展开独立插图；只有确认最后一句时才更新 `state.residents.heard`；切话题、关闭或仅看图均不收藏。
- 主线 8 张保留已有 CG ID 与解锁旗标；不动冻结对白、TTS 或已有影片文件。
- 画廊沿用 `jiangcheng-lights-gallery-v3`，主线的 `memory-*` 收藏 ID 不变；新增 36 张使用 `wuhan-*` 收藏 ID。44 张记忆加原 4 结局、3 成就，共 51 张。
- 27 段街坊旧事在画廊大图下附原有对白，可静静重读；现场交谈继续在 3D 世界里进行。
- 新地图的观察点可引用已有图作为线索，不自动替玩家完成居民旧事。
