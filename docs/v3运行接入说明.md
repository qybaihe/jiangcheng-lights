# v3 运行接入说明

本文件说明代码合同；影片最终生成、质量与声音验收分别见媒体生产记录。

## 运行分工

- `main.js` 通过 `MEMORY_BOUNDARIES` 触发章节，不按写死的旧数组下标判断回忆。
- 进入某段第一句 memory 时播放 granny / chef / dock / ending；播放结束或跳过回到该段 endExclusive 的现在时台词。影片包含的回忆对白不在电影后重读。
- 用户点“暂时离开”时，只退出此次对话，不执行 onDone 和任务 flag。故障可回到同段第一句 memory，用原有 CG 和新对白手动推进。
- 好结局共享 ending 的童年影片，但回到现在后改接 endingGood。真结局接认可稿的完整现在时电话。离开分支不播放“晚两天”的旧电话。
- `towel` 是世界里的独立观察按钮和可选静态回忆；不观看不影响社区准备。新周目只在看完后解锁其旧照；旧存档保留此前已看过的版本。
- 童画是 2×2 四片空间拼合，单击两片或拖动交换；用连续图案观察，不按私人往事时间排序。
- 风险任务在现场发送并收到回执后落 flag；“看不清”可以如实报告，记录状态为 unclear，不伪称观察到了细节。

## 电影 manifest

路径：`/media/cinema-v3-manifest.json`。

```json
{"version":3,"scenes":{"granny":{"title":"一碗面，一张竹床","url":"/media/cinema-v3-granny.mp4","duration":32,"poster":"/media/story-v2-cg-granny-table.webp","stems":{"music":"/media/…-music.mp3","effects":"/media/…-effects.mp3","voice":"/media/…-voice.mp3"},"cues":[{"start":1.2,"end":2.8,"lineId":"granny-memory-entry","who":"林婆婆","text":"面要坨了，先吃。"}]}}}
```

- cues 可为数组，也可为本地 JSON URL；外置 JSON 可是数组或 `{cues:[…]}`。
- stems 是从零开始、与影片等长的三条连续轨；对白之间的静音留在轨中。voice 也支持 `{female:URL,male:URL,default:URL}`。
- 有 stems 时视频始终静音。音乐、音效、对白分别使用已保存的音量；页面 BGM、雨声、逐句 TTS 在影片开始时停止。
- 视频是唯一时间钟。暂停、seek、变速、隐藏标签页同时作用于声音。隐藏后保持暂停，避免回来时突然出声。
- 关闭销毁音视频 src、取消回调；延迟加载不再触发剧情完成。

## 分支与存档

- community 第一次请求时记录 commitment：help / undecided。
- shop 或 dock 可看离开安排，两次确认后产生 neutral / regret；不补写 checked / ending。
- checked 后回铺选择 stay：breakfast / leave。没有四种结局菜单。
- 结局规则、画廊持久化由 `endings.js` 负责，画廊由 `gallery.js` 展示。
- 选择前保存 endingFork，结局写入 lastEnding / runEnded；早走后继续任务需明确恢复分岔点。恢复不清除画廊，也不凭空完成工作。
- 已完成旧周目保留原真结局；展示优先读取已记录结局，而非事后新增收集重新推算。

## 验证脚本

- `tests/cinema-player.test.js`：时间钟、暂停、seek、音量、故障、销毁与过期回调。
- `tests/cinema-assets.test.js`：最终本地素材、各句 memory 的 ID/文字/说话人、字幕时长边界。媒体 manifest 未落盘时明确跳过；不能把跳过算成素材验收。
- `tests/cinema-v3-browser.mjs`：隔离存档的真实 UI 路径；使用明确标注的影片 stub，验证控制流，不认证最终片质。
- `tests/cinema-final-browser.mjs`：真实最终文件，通过生产播放器检查三轨长度、字幕、同步、音量与销毁；应在素材发布后运行。

### 收口的运行边界

- 电影每条音轨只有一个 pending play；缓冲、暂停、seek 引起的 AbortError 不再被误报为声音失败。真实解码/权限错误仍显示恢复入口；销毁后忽略过期回调。
- 新周目进入时写入 storyV3 标记，避免进度到 prepared 后刷新误触旧存档毛巾补偿。
- 提前离开结束周目后，现场毛巾与离开按钮不绕过 runEnded 门槛；恢复分岔后才继续当时的事。
- 天气栏与人物去向一致：雨前准备、巷里听雨、收到公共主巷确认后的雨后散步分开。
