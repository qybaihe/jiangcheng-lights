# 《江城有灯》首次试玩记录表

用途：对同一候选构建开展 3 名首次玩家的无攻略试玩，记录主线容量、找路、武汉辨识和剧情理解。本表尚未执行；所有结果栏均留空，完成一次填写一次，不用自动化通关或旧版本数据代填。

依据：[参赛统筹方案](参赛统筹方案.md) 与 [设计与验收](设计与验收.md)。本表分为可交给玩家的说明和仅主持人查看的记录／判定部分；不要将后者提前发给玩家。

## 一、执行前准备（主持人）

- 找 3 名未玩过、未读过本项目剧情和攻略的玩家，分别测试，互不观看或交流。武汉生活经历单独记录，不以是否来自武汉筛掉不会操作游戏的人。
- 固定候选构建。每位使用独立的新存档，确认没有主线完成旗标或已收集物品；保留测试结束后的存档，后续测试换独立浏览器配置或清理其专用测试存档，不覆盖真实用户进度。
- 至少安排一位使用手机或对应移动操作方式，并记录是真机还是桌面模拟。手机真机性能是否通过仍需专项报告，不能由一次能玩完推断。
- 先做无标题截图盲认，再进入游戏；盲认时不要说游戏名、武汉、汉口、江城或比赛主题。使用同一候选构建的实机截图，不用生成宣传图代替；文件用中性编号，去掉标题、HUD、可读城市名及文件名中的地点词，保留场景本身的建筑、江面与生活细节。
- **不要在正式计时中追问剧情或解释解法。** 主持人安静记时间和行为，理解问题在通关或终止后再问，避免访谈把游戏时间撑长。
- 主持人准备独立计时器。获得许可后可录屏供核对；无录屏也可人工记下每个阶段的累计时间与卡点。操作中断、设备问题和主持人介入需单独记时。
- 若中途发现阻断缺陷，先记录、停止该次测试并保留存档。修复后的重玩已不属于同一玩家的首次体验，不能混入本轮首次主线中位数；需要另找首次玩家补样本。

## 二、玩家版说明（只展示本节）

请先看主持人提供的几张场景截图，再回答截图问题。没有标准答案提示，按照你的第一印象说即可。

接下来，请从新故事开始，按你平时玩游戏的方式体验。可以阅读、探索、调整游戏提供的设置，也可以查看游戏里的地图、手账和操作指南。请自己决定先去哪里、怎样处理遇到的事情；不查攻略，也不向其他玩家询问。

你不需要刻意快走、慢读或把时间拖到某个长度。遇到疑惑可以说出来；主持人通常只记录，让你先自己试。若希望获得帮助，或出现不适、设备故障，请直接提出。你可以随时暂停或停止，停止不会被视为你的问题。

当你认为主线故事已经结束，请告诉主持人。之后会问几个关于理解、找路和操作的问题。补收集和重看内容可以继续玩，但会单独记录。

## 三、无标题截图盲认（进入游戏前）

每位玩家单独看同一组 3–5 张截图。截图应覆盖不同视点，并包含城市轮廓与生活场景，不能只用贴有城市名的招牌。先问第一题并记录原话，再追问依据；不提供城市选项，不说“猜得很接近”。

**玩家问题：**

1. 第一眼，你觉得这可能是哪座城市或什么地方？不确定也可以说不确定。
2. 画面里的哪些东西让你这样判断？请指给我看。
3. 如果没有那些明显的建筑，你还会作同样的判断吗？还有哪些生活细节支持它？
4. 哪个地方让你觉得不自然，或像拼在一起的？

## 四、正式试玩计时和逐阶段记录

### 计时口径

主线开始：点击新故事并首次获得 3D 行走控制。主线结束：首次完成结尾对话并出现尾声结果；由主持人核对，不因玩家提前猜到结尾就停止计时。

**主线有效用时 = 首次控制至尾声的墙钟用时 − 非游戏中断 − 可选影片 − 可明确区分的支线停留。** 正常主线阅读、走错路、查看游戏内地图／手账／帮助、失败重试均计入；设备故障、离席、主持人访谈等不计入。外部提示不抹掉此前用时，但该次标为“有主持人帮助”，不得宣称无攻略完成。可选电影、支线收集和通关后自由探索另记耗时；各类时间只归属一项，无法区分的混合探索需注明，不擅自估算减去。

主线记录以独立计时为准，存档中的 `milestones` 为交叉核验：这是首次合法获得 flag 时的累计游玩秒数，不是墙钟日期。旧存档缺少里程碑时不能倒填；若明显与墙钟不符，先记录原因和差值。没有任何最低时长等待条件，短于目标也按真实结果填写。

## 五、通关后理解访谈

仅在正式计时结束后进行。未通关者只问已见过内容，未经历部分留空。先记录原话，再用主持人判定表核对；不在题目里讲出结尾。

### 玩家问题

1. 用自己的话说，你扮演的人为什么回来？一开始想做什么，最后有什么变化？
2. 依照你实际遇到的顺序，每位街坊分别让你新知道了什么？有没有两段让你觉得在说同一件事？
3. 你帮过的人，后来具体帮到了什么？请举你在游戏里看见或确认的例子。
4. 取齐东西之后，还有什么事情需要完成？你是从哪里知道的？
5. 社区那一段，哪些事情由你负责，哪些交给别人？你怎么知道事情已经办妥？
6. 最后那段让你怎样理解之前的经历？有没有哪条消息出现得太早、太晚，或和你已经做过的事对不上？
7. 哪个时刻让你觉得温暖？哪个时刻只是等着看字或等画面结束？
