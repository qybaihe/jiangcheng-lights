## 这一轮交付

不替换主线的演员、配音或 BGM。补齐街坊闲聊、武汉观察点与旧物探索；场景短拟音单独供运行时调度。

阿遥的 15 句同时制作男女版；书信、牌面与旁白按叙事身份朗读，不临时换成主角。

- 实际配音合计 **1155.84 秒**，约 **14.0 MB**（十进制）。这是可选内容的全部录音长度，不是强制游玩计时。
- 所有配音为 48 kHz 单声道 MP3，194 个文件全部解码、检查 SHA-256 与响度。
- 实测综合响度 **−20.44 至 −18.86 LUFS**；最高真峰值 **−2.09 dBTP**。目标 −19 LUFS、上限 −2 dBTP。
- 原有 `story-voice-manifest.json` 与 `story-music-manifest.json` 保持独立，新包没有旧台词 ID。

## 接口契约

素材清单：`/media/town-audio-v1/manifest.json`。

`lines[lineId]` 延续主线的 `text / sha256 / speaker / variants` 结构。`variants` 对普通街坊为 `default`，阿遥为 `female / male`；每条含本地 URL、时长、演员 profile、音频 SHA、大小及编码后响度。前端继续使用精确文本一致性检查，文本改动时不播放旧句。

`src/supplemental-audio-lines.js` 从现有故事源读取文本，**没有另抄或重写一套台词**：

```js
residentGreetingAudioLine(residentId, phase) // beforeRain | warning | afterRain
residentTopicAudioLine(residentId, topicId, index) // index 从 0 开始
districtAudioLine(stopId, index)
adventureAudioLine(stopId, index)
loreAudioLine(loreId)
```

未知 ID、阶段与越界索引返回 `null`；ID 统一以 `town-` 开头。进度、解锁、自动翻页不由音频模块决定。

## 场景拟音

补充包提供 14 个 cue；其中 12 个新生成，江风与水声复用项目已生成的电影音效源并重新做低声场景循环。原来的 `page / radio / rain` 继续使用旧包，不重复覆盖。

| cue ID | 用途 | 时长 | 建议 gain | cooldown（毫秒） | 循环 |
|---|---|---:|---:|---:|---|
| map-fold | 展开地图 | 1.8 s | .48 | 180 | 否 |
| ui-confirm | 修好/确认的小扣合 | 1.2 s | .50 | 700 | 否 |
| collect | 照片收进手账 | 1.5 s | .42 | 800 | 否 |
| car-door-open | 上车开门 | 1.4 s | .48 | 500 | 否 |
| car-door-close | 关门 | 1.0 s | .42 | 500 | 否 |
| engine | 启动车辆的一次短声 | 3.0 s | .36 | 1500 | 否 |
| bicycle-freewheel | 下车时轻轻空转 | 1.8 s | .34 | 1000 | 否 |
| chair-sit | 竹椅与衣料的小响动 | 1.5 s | .35 | 700 | 否 |
| ferry | 船边轻水，缓缓离岸 | 3.0 s | .36 | 1500 | 否 |
| breakfast | 过早铺锅边环境 | 11.0 s | .40 | 0 | 是 |
| breeze | 江城轻风环境 | 11.0 s | .28 | 0 | 是 |
| water | 近江轻水环境 | 11.0 s | .38 | 0 | 是 |
| bicycle-bell | 一下车铃 | 1.25 s | .33 | 1000 | 否 |
| car-horn | 礼貌短喇叭 | .9 s | .28 | 1200 | 否 |

`gain` 为线性 0–1，`cooldownUnit` 明确为 `ms`。环境源约 −29.4 LUFS；短声目标约 −23 LUFS，瞬态保留余量。建议值刻意较轻，运行时可结合 BGM 与总音量微调，不需要重新生音频。三种环境只选择一条播放，不多层无上限叠加；对白时继续压低、切电影与后台时停止。

短音有 50 ms 边缘淡入淡出，循环音使用 650 ms 环形交叠，不靠音量骤降或长静音遮住接缝。所有最终文件无削顶，真峰值低于 −2 dBTP。

## 生成、重试与验收证据

```sh
uv run --with edge-tts==7.2.8 --with httpx --with python-dotenv python tools/town_audio.py voice --concurrency 4
uv run --with httpx --with python-dotenv python tools/town_sfx.py --workers 2
uv run --with httpx --with python-dotenv python tools/town_audio.py publish
uv run --with httpx --with python-dotenv python tools/town_audio.py verify
```

- 语音断点状态、原始输出与哈希：`output/audio/town-audio-v1/voice-jobs.json`、`raw/`。
- 音效提示词：`media/prompts/town-audio-v1/`；原始 WAV、请求指纹：`output/audio/town-audio-v1/sfx-raw/`。
- 全量配音解码/响度：`output/audio/town-audio-v1/voice-verification.json`。
- 代表样本与真实循环接缝通过中性画面载体进行模型辅助听音，未向审听模型提供预期台词或音效说明；原观察保存在 `output/audio/town-audio-v1/listening/`。它是实际文件审听记录，不标记为人工听完全部 194 条。
- 首次试配的程岚、宋远 ASR 字形有歧义，独立复听已能辨认正确的 Chéng Lán / Sòng Yuǎn；原记录与复核同时保留。
- 早餐与渡船 v1 语义偏泛，另做 v2 并保留旧输出，不用重命名假装通过。
- `tests/supplemental-audio-lines.test.js` 与 `tests/supplemental-audio-assets.test.js` 检查 179/194 精确覆盖、角色绑定、本地文件哈希、峰值、14 cue 与 cooldown 单位。

凭证仅由离线接口模块在内存读取；本次 TTS 使用原有无需项目凭证的 Edge 接口。前端只请求项目本地静态音频。
