# 《江城有灯》场景道具互动 v1 · 交付与验收

日期：2026-09-12。试玩：[新版晴川里](http://127.0.0.1:4173/?v=props-v1)。

## 一、交付范围

不是用一张菜单说明“你骑过车”，而是让人物与场景实物产生可见绑定：**借车骑行 → 停在哪里，下次就在哪里找；坐下读报 → 椅子、双手与纸张在 3D 中；登船看江 → 船与人物真的沿岸移动。**

入口为顶部 **⌂ 巷中生活**、地图中的三个道具地点及手账的“巷中生活”页。道具使用 **F**，与原有 **E** 街坊/委托交互分开；地图到达提示也显示 F。

### 1. 借一阵顺路的风：自行车

- 修理铺附近的老式通勤自行车可以主动借用，不消耗任务物资。
- W/S 前进、后退，A/D 转向；最高设定 6.8 米/秒，普通步行 3.4 米/秒。空格为两击金属车铃，不再跳跃；铃声遵循音效音量与总静音。
- 男女主角均有骑姿、握把和脚踏约束；车轮、曲柄、踏板随实际位移运动。
- 碰撞使用沿行驶与转向扫过的完整车身体积，包含邻居、墙、风险边界及低雨棚；缓坡可骑，台阶会阻挡。不是把步行速度直接乘二。
- F 停车，寻找车旁合法落点；车辆位置和方向随存档保留，重新载入后人在地面，不自动骑上车。
- 骑行中打开地图立即制动但仍保持骑行状态；剧情、设置等其他面板触发安全下车。

### 2. 坐一会儿再走：竹椅与小报

- 人物坐进修理铺旁的竹椅，拿起《晴川里街坊小报》；桌上有茶杯与折报，手持时桌上折报隐藏，收起后恢复。
- 阅读卡在右，真实街景保留在左。两款角色的坐姿、手指和持纸位置已校准；镜头把人物放在画面左侧，避免正文遮住脸和双手。
- 左右方向键翻页，上下方向键/滚轮阅读长正文；拖动左侧可以看四周。“收好报纸”或 Esc 收报并起身。
- 雨前、雨后两期，每期三则街坊新闻、一则旧广告、一条页边暗示。武汉日常落在里分竹床、过早、豆皮、饭盒、轮渡和街坊口语里。
- **工作台上的作业本**与**便民栏不同的笔迹**是叙事回声，不提前解释主线真相；记进手账后可引路回修理铺/社区。
- 仅翻到第二页才记“已读”，只有主动点击才记下暗示。打开报纸不自动收集、不替玩家完成主线，也不解锁结局。
- 只有本周目完成雨后通行消息 `postlude`，才换雨后号；3D 手中纸面和右侧正文使用同源数据。

### 3. 把脚步交给江风：近岸渡船

- 岸内候船点查看当班告示并主动登船。小船有船员、座椅、棚顶、踏板与救生圈；岸边周伯与船员是不同人物。
- 正常近岸往返约 26 秒，船体与角色连续移动，视线经过钟楼、桥影、岸线，最后回到原码头。这是观江短线，不是新建一张跨江地图。
- “提前靠岸”播放约 3 秒回港动作，按钮禁用直到到岸；提前回港不增加完整航次。
- 完整往返只记一次。设置/退出面板等强制离开路径会安全落回岸内。
- 进入准备/核对阶段 `prepared` / `checked` 后暂停登船；雨后由当班告示明确确认这条短线复航，小报不把“雨停”写成自动恢复通航。
- “减少动态”停止装饰摇晃，不停止船程。乘船中保存的是岸上落点，刷新不会落入江面。

## 三、数据与原主线隔离

道具存入独立的 `state.props`：借用状态、停车位置/朝向、读过的版次、主动记下的暗示、完整航次。运行时姿态、座椅高度、水面位置和临时镜头不作为普通步行存档。

恢复顺序为**先恢复车辆，再恢复人物陆地落点**。旧存档缺道具字段时正常补默认值。读报/乘船刷新回到合法地面；重开本周目清道具进度，跨周目画廊保持独立。现有四种结局判定、主线对白、电影与配音资源未因本轮道具交互而改写。

动态自行车与小船不加入静态几何批处理，也不触发每帧烘焙阴影刷新。
