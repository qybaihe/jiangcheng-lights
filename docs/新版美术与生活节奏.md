# 《江城有灯》新版美术与生活节奏

更新：2026-09-08。对应本轮实机改造；下列效果已有代码实现，整体体验仍以最终集成验收为准。

## 实际修改

| 部分 | 本轮变化 | 实现位置 |
| --- | --- | --- |
| 天空与空气 | 清透蓝天空、平视可见的层状白云；晴天、雨天、雨后各有背景，雾与环境填充缓慢调整。环境只预计算一次，不逐帧捕捉。 | `src/atmosphere.js` |
| 建筑 | 保留立面上招牌、窗口内容、砖缝；按原有测量区域局部整理墙灰和绿色木作，减弱大片污渍。法线强度从 0.28 降至 0.13，减少粗糙噪声。 | `src/architecture.js` |
| 植物 | 树叶改为嫩绿、浅金的受光层次；小幅顶点风动不增加网格数量，减少动态时停风。盆栽叶片、陶盆同步调色。 | `src/architecture.js`、`src/props.js` |
| 人物 | 五档卡通光照，肤色、衣服、鞋与发色统一；头和双臂从躯干拆出独立支点，仍保留原衣领、发丝、面部与围裙细节。 | `src/characters.js` |
| 过早铺与旧物 | 蓝白瓷碗、芝麻酱与面条、葱花、竹木和金属分别调整明度与色彩，保留实际模型细节。 | `src/food-stall.js`、`src/props.js` |
| 武汉地标与远岸 | 钟楼浅石色、大桥蓝灰钢架、轮渡与楼阁材质协调；新增连续远岸地形、护岸步道、钟楼广场、桥头岸台与楼阁低丘，使地标有陆地依托。地标主体的轮廓、位置及比例保留，轮渡航道与可玩区不变。 | `src/landmarks.js` |
| 物资与互助成果 | 可领取物资改为独立组，领取后在原处隐藏；蔡姨任务完成后，热食打包箱出现在摊位，`checked` 后转移至社区。 | `src/world.js` |

这次改变包含天空、材料和人物着色，不以提高全局曝光代替美术调整。墙灰整理在纹理加载时执行一次，不在逐帧渲染中处理像素；原始图片文件保留，便于追溯。

## 街坊的动作

统一入口为 `updateTownLife(world, dt, time)`，已由世界更新循环调用。角色站位与家具布局没有因动作而改变。

| 街坊 | 日常动作 | 与任务／交谈的衔接 |
| --- | --- | --- |
| 林婆婆 | 手持小纸扇，扇几下、停一会儿，轻微看向街巷。 | `granny` 完成后增加安静停听的时间；交谈时减弱扇动、面对玩家。 |
| 蔡姨 | 手持抹布擦手、放下，再抬眼看下一位街坊。 | `chef` 完成后缩短整理时间，转为等候出发前的从容状态。 |
| 周伯 | 手中保温杯随手臂自然移动，慢慢望向江面。 | 不伪造喝水、递杯或搬箱动作；交谈时收住望江姿态。 |
| 小许 | 抬起夹板查看，再抬头照看街坊。 | `prepared` 后缩短核对动作；名单和夹板始终跟随左臂。 |
| 普通路人 | 在主巷短段行走、停留、缓慢转身，再走回去。 | 每次移动验证可走位置，靠近玩家或其他居民时礼让，不占用主线交谈点。 |

扇子、抹布、杯子与夹板合并进对应手臂的网格，避免物件和手分开运动。动作主要通过肩部、髋部和头部支点实现，没有完整肘、膝、手指骨骼或动作捕捉；本轮不宣称具备端碗、拌面、擦桌等复杂人—物接触演出。

玩家步态使用碰撞后实际移动距离，贴墙不继续原地“跑步”。减少动态时，人物回到中立姿态，路人暂停移动；交互与任务位置仍然可读。居民雨中是否在室外继续服从世界的既有天气逻辑，本轮没有制作完整“收摊—走进屋”的过场。

`world.storyFlags` 驱动上述节奏变化。世界模块已将保温箱、饮水和备用电池分别建为独立物资组，通过 `world.collectedSupplies` 在领取后隐藏。热食打包箱在 `chef` 完成后于摊位出现，`checked` 后显示在社区位置，任务成果已能在 3D 场景中看见。这是已实现的物资显隐与位置反馈；尚无人物抱起、沿路搬运、放下箱子的完整动作演出。

## 预算与检查

- 每个角色现在是 **6 个共享材质网格**：躯干、头、两条手臂、两条腿；此前是 3 个。手持细节没有增加独立绘制对象。实际整帧绘制调用还包括反射、阴影和后处理，不能直接拿角色网格数当作整帧 draw call。
- 树叶仍使用既有实例化网格；风动只更新一个时间值，不每帧重建几何。
- 日常动画每帧不分配几何；人物静态阴影缓存与脚底接触阴影由世界渲染模块管理，本模块不修改其投影策略。
- 已执行五种人物的 20 秒数值模拟：每人 6 网格、无非有限顶点、身高约 1.62–1.80 米；减少动态后的手臂能回中立。
- 已用真实 Chrome 渲染人物与整街，所检查页面无脚本或控制台错误。此处是有范围的实现检查，不替代全部任务和真机性能验收。

## 当前边界

本轮实机美术使用既有生成纹理、手工重建几何与卡通人物着色，没有为这次美术改造制作新的生成图或视频。可玩街区的道路与建筑布局没有扩建，远景则已补建连续岸地、护岸、桥头平台和钟楼广场。建筑内部仍有绘画图层，人物仍是轻量程序模型；**不能宣称已经达到离线生成图片的等质三维重建**。上述已实现反馈和几何改动不等于最终画质验收通过。

立面仍保留历史使用痕迹，部分室内图片和旧物材质比新角色更写实，后续可以继续统一笔触与细节密度。三条已制作的 Seedance 样片、既有回忆插画仍属于旧版美术，需要按新风格另行统一，不能因实机提亮就一并标为改版通过。

开阔江面的尺度、可辨认的武汉轮廓与真实可走街巷继续作为基础；动画和亮色服务于生活感，不替代故事内容，也不用于凑满 15 分钟。
