# 阿遥角色素材来源与使用条件

适用文件：女款 `public/models/ayao.vrm` 与男款 `public/models/ayao-male.vrm`（发布后的 `/models/ayao.vrm`、`/models/ayao-male.vrm`）。

本项目以 **VRoid AvatarSample_A（女款）和 AvatarSample_C（男款）** 为角色美术改编基础。原始模型由 **pixiv Inc. / VRoid** 提供，模型作者元数据均为 `VRoid`。《江城有灯》对其进行项目角色的美术改编与游戏集成；原始人物模型及其全部基础素材并非本项目完全原创。

## 来源

- 官方女款模型页：[VRoid Hub — AvatarSample_A](https://hub.vroid.com/en/characters/2843975675147313744/models/5644550979324015604)。
- 官方男款模型页：[VRoid Hub — AvatarSample_C](https://hub.vroid.com/en/characters/1248981995540129234/models/8640547963669442173)。
- 官方许可：[VRoidPreset_A–Z 使用条件](https://vroid.pixiv.help/hc/en-us/articles/4402394424089)。AvatarSample_A 与 AvatarSample_C 的官方来源链接和适用条件均在该说明中。
- 女款实际下载来源：[madjin/vrm-samples 中的 AvatarSample_A.vrm](https://raw.githubusercontent.com/madjin/vrm-samples/master/vroid/stable/AvatarSample_A.vrm)。
- 男款实际下载来源：[madjin/vrm-samples 中的 AvatarSample_C.vrm](https://raw.githubusercontent.com/madjin/vrm-samples/master/vroid/stable/AvatarSample_C.vrm)。两者均为第三方免费分发镜像，不是 pixiv 自有仓库。
- 镜像文件的模型元数据与保存的原始文件已核对；尚未将其与官方 Hub 最新导出文件做完整哈希比对，不能声称两者版本完全相同。
- 女款与条款核实日期：2026-09-09；男款下载与元数据核实日期：2026-09-10。官方条款的原始 API 响应、HTML 原文与证据 URL 保存于 `output/qa/character-art/`；男款原文件、来源记录及改编记录保存于 `output/qa/character-choice/`。

该模型适用 pixiv 的样例模型专用使用条件，**不是 CC0，也不应被标为“完全原创模型”**。模型内 `licenseName=Other` 不表示放弃版权；具体条件以上述官方条款为准。

官方允许任何人用于营利或非营利活动，包括将其作为支持 VRM 的应用/平台中的角色、制作图像与视频、修改纹理及参数，以及分发改编模型；使用时不强制要求给原作者署名。本项目保留上述来源以便参赛素材核查。

本项目的使用范围为角色美术改编和游戏集成，模型作为游戏角色素材随免费游戏演示/参赛包提供。分发时继续保留本来源说明及官方条款链接，不收费再分发原始样例文件或其中素材，不以本项目对其他文件的授权覆盖模型自身条件。

当前改编包含服装与头发配色、纹理资源优化及游戏中的独立斜挎包等配件；基础人物、服装几何与原始纹理设计仍来自上述样例。阿遥的人物故事与项目配件设计不改变基础模型的素材来源和使用条件。

女款采用米白针织外衣、玉绿配色和柔和栗发；男款采用深栗短发、自然棕色虹膜、鼠尾草绿与米色休闲夹克、墨绿长裤。两款均保留样例的基础几何、骨骼、蒙皮、脸部细节和表情系统，不能把配色改编描述为完全原创人物建模。
