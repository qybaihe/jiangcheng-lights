# 江城有灯

一条虚构的武汉汉口老巷，一场大雨，一群互相照应的人。Three.js 连续街区探索、场景内交谈、可操作的旧物谜题、主动展开的旧照画册与剧情视频。

## 操作

- WASD / 方向键行走，Shift 跑步，空格跳跃；双击可通行地面可以规划步行路线。空中按 E 会在落地后尝试交谈，长按空格不会自动连跳。
- 靠近人物、旧物或城市拾光点，按 E / 点交互按钮。
- 点击场景人物，或靠近按 G，问好并选择闲谈话题。人物会停下、转向主角，故事不离开 3D 场景；选话题、听完、重听均不代做主线。
- 点击停放车辆或靠近按 F 进入驾驶座；W/S 前后、A/D 转向、空格鸣笛、F 下车。场景内两辆汽车均可驾驶，碰撞会阻止穿过人、车、墙和台阶。
- 靠近自行车、竹椅报桌或渡口，按 F / 点道具按钮。骑行用 W/S 前后、A/D 转向、空格按铃、F 停车；M 看地图会制动但不下车，其他剧情或设置面板会安全下车。
- 坐下读报时，左右方向键翻页、上下方向键或滚轮读正文；拖动左侧街景看四周，“收好报纸”或 Esc 起身。翻到夹页才记录已读，明确点“记进手账”才保存暗示。
- 渡船正常往返约 26 秒；“提前靠岸”用约 3 秒回到岸边，不计作完成一趟。读报或乘船中刷新，会站回合法陆地点。
- 顶部“江风来信”追随可选的三站线索。靠近燕子、风铃与高台旧灯后按 E 阅读；阅读时可拖动看四周，读完才记下线索，Esc 可以暂时离开。
- V 或右上按钮切换第一人称、近景跟随和全景。跟随视角可拖动观察、滚轮调远近；第一人称点“鼠标观察”锁定鼠标，Esc 退出。
- M 打开精绘地图，可缩放、拖动、选地点看路线；“开始引路”保留手动探索，“走到这里”自动步行。J 打开任务、物资去向和街坊互助手账。
- 与街坊交谈时保留真实 3D 街景，镜头靠近人物；可以拖动观察周围，角色暂停行走。
- 对话中点“下一句”，或空格/Enter；支持上一句、暂时离开、记忆回看。只有进入年轻时代的往事才切换 2D，结束自动回到街坊身边。
- 顶部 **◇** 打开江城画廊，可分类看画、重温已解锁影像、确认后返回结局分岔点；重开故事保留本机画廊收藏。
- Esc 关闭弹层；设置中有声音、减少动态、流畅画质及重新开始。
- 手机有屏幕方向键，桌面浏览器是本版主验收平台。

## 内容

四幕主线、四位主要街坊、三家旧物往事与可选毛巾回忆、三类谜题（接线、童画拼合、应急包）、三处物资搜寻、两处风险辨识、六项武汉城市拾光。v3 正式口播共 169 句，含可选重访及互斥结局内容，不能直接相加作为单次游玩时长。时长目标为首次主线 18—25 分钟；真实的 ≥15 分钟验收需 3 名首次玩家测时，自动化快速通关不作替代。

《晴川里》和人物经历均为虚构；江汉关、武汉长江大桥、轮渡、过早与汉口建筑元素用于建立城市辨识度，地理位置和距离经过压缩。

## 场景细化

本轮默认使用约 4.6 米的近景跟随镜头，靠墙自动侧移、缩短距离，离开后平滑回正。移动使用带加减速的速度向量和空中转向；主角有连续蒙皮衣袖、裤腿、20 根骨骼，跑步包含双脚腾空、起跳收腿、下降展开和落地缓冲。背包与发梢使用弹簧跟随，鞋底按实际地面补偿。跳跃约 1 米 / 0.6 秒，身体同时检查横向墙体与头顶雨棚。普通对话根据实际字幕框高度调整构图，保持人物处在字幕上方。

手动拖动从当前实际视线连续转向，拖动期间靠墙只收短镜距；松手后的辅助侧移有速度限制。镜距过近时仅主角平滑淡出，离墙后恢复，街坊和对话中的人物保持清楚可见。

21 栋街屋统一为原创实体门窗、窗台、厚墙、曲瓦屋面和侧后立面，修理铺与面铺各有 2.2 米深的可进入门廊。不同街屋使用陶土、暖奶油和青灰配色。陆记侧牌、小院晾巾、过早布旗、通勤自行车和街坊手持物形成近景细节。静态建筑按街区分格合批，使用缓存阴影、细轮廓和边缘抗锯齿；玩家跳起时接触阴影随高度变淡。最新实现与实机证据见 [跑跳与精细场景验收](docs/跑跳与精细场景验收.md)。

修理铺西侧新增工具借用小巷，经十二号院门与 1:12 缓坡进入小院；早餐铺旁新增可穿行侧巷。小棚、院墙、扶手和坡面均有实际体积与碰撞，地图按同一份空间数据绘制。11 棵梧桐改为连贯树干和成组树冠，叶缘轻动；全景天空的云层首尾相接，转身观察没有硬接缝。

早期生成原画用于探索方向；当前街屋不再用照片式正立面作为最终外观。近景保留细化的收音机、竹椅、蕨类、热干面与木柜。人物、江汉关风格钟楼、长江大桥与渡船也已细化。镜头会避开建筑、雨棚与树冠，并在交谈时把人物分开构图；大件家具参与行走碰撞，城市拾光有场景微光提示。

截图见 `output/qa/`，美术目标与当前不足见下面的重建说明。

## 离线素材制作

`.env` 仅用于制作，不进入 Git 或前端。依赖：Python、OpenAI SDK、Pillow、httpx、python-dotenv，另需本机安装 imagegen 技能 CLI。首次设置可运行：

```bash
uv venv .venv
uv pip install --python .venv/bin/python openai pillow httpx python-dotenv
```

`tools/media.py` 支持图像、视频、语音制作；已有文件会保留，视频任务会保存状态供继续查询。调用会使用用户配置的付费模型接口。具体提示词与调用方式见素材清单。

本版采用原画参照和原创几何；当前街屋的门窗与屋顶均为实体建模，部分旧物和路面保留贴图。这不是自动神经三维扫描。修理铺与面铺可进入浅廊，其余民居不提供完整可游览室内；武汉盲认、首次玩家时长和应急专业审校仍需真实受试者与专业人员完成。
